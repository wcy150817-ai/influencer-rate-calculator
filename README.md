# Influencer Rate Calculator (2026)

> Free sponsorship and brand deal pricing calculator for content creators across YouTube, TikTok, Instagram, and X.

🌐 **Live Website**: [https://influencerratecalc.com](https://influencerratecalc.com)

## Features
- **Multi-Platform Support**: YouTube, TikTok, Instagram, X (Twitter), and Newsletters.
- **Dynamic CPM Valuation**: Based on median views, creator tier, and vertical niche multipliers (Finance, Tech, Lifestyle, Gaming, etc.).
- **Deliverables & Rights Pricing**: Dedicated videos, 60s integrations, shoutouts, plus 30-day paid ad whitelisting and exclusivity clauses.
- **One-Click Pitch Generator**: Copy-paste ready professional brand pitch and response email scripts.
- **2026 Benchmark Matrix**: Comprehensive creator economy reference table.
- **Client-Side Privacy**: 100% runs in browser, no personal data uploaded.

## Tech Stack
- **Framework**: Next.js 15+ (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React & inline SVGs
- **SEO**: Fully optimized JSON-LD schema, OpenGraph tags, sitemap.xml, robots.txt

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
